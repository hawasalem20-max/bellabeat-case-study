# Bellabeat Case Study

## Project Overview

This project analyzes Fitbit smart-device usage data to identify trends in physical activity and sleep. The goal is to use these insights to make recommendations for Bellabeat's marketing strategy.

## Business Task

Analyze Fitbit smart-device usage data to identify trends in how consumers use smart devices for physical activity and sleep, and apply the findings to a Bellabeat product.

## Tools Used

- Google Sheets
- Data cleaning
- Data analysis
- Data visualization

## Key Findings

- Users averaged **7,638 steps per day**, below the 10,000-step goal.
- Users averaged **991 sedentary minutes per day**.
- Users averaged approximately **7 hours of sleep per night**.
- On sleep-recorded days, **40.24%** also reached 10,000+ steps.

## Recommendations

1. Encourage users to increase daily movement through step challenges.
2. Reduce sedentary time through movement reminders.
3. Promote sleep tracking through personalized sleep insights and bedtime reminders.
